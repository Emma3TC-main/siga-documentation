# Diagramas canónicos — SIGA v1.2

Los `.puml` de esta carpeta son **fuentes canónicas**.

- Usar estos archivos para arquitectura, implementación, trazabilidad, revisión y agentes de IA.
- No sustituirlos por versiones preparadas para informe.
- Los derivados de presentación se encuentran en `../diagramas_render/`.
- Si existe una divergencia, este árbol prevalece sobre `diagramas_render/`.
- La precedencia completa se define en ADR-018 y ADR-019.

**Importante:** los archivos canónicos de v1.2 se mantienen intactos; las mejoras visuales derivadas de v1.1 se aplican fuera de esta carpeta.
